# fruit_type.dart

## Overview
`fruit_type.dart` defines an enumeration of all the different fruit types available in the game.

## Implementation Details
1.  **Enum**: Uses a standard Dart `enum` to provide a type-safe way to reference specific fruits.

## Code Breakdown

### 1. `FruitType` Enum
```dart
enum FruitType {
  apple,
  banana,
  watermelon,
  ...
}
```
*   Each entry corresponds to a specific visual asset and game color.
